# Handwritten Digit Recognition

## Project Overview
This project recognizes handwritten digits (0–9) using Machine Learning. It is trained on the MNIST dataset and predicts the digit from an input image.

## Features
- Recognizes handwritten digits
- Uses the MNIST dataset
- High prediction accuracy
- Simple and easy-to-use interface

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib

## Dataset
- MNIST Dataset
- 60,000 training images
- 10,000 testing images
